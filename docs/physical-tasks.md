# 물리 작업 체크리스트 (하드웨어 셋업 — 손으로 하는 것 전부)

> 소프트웨어/설정은 별도. 이 문서는 **손으로 해야 하는 작업**만 순서대로 정리한 것.
> AI/도우미에게 위임 가능하도록 단계·주의사항·핀맵 포함. 소프트 연동은 `docs/control-map.md` 참고.

---

## 0. 구매 목록 (물리 작업 전에)

| 물품 | 용도 | 비고 |
|---|---|---|
| **인두기 + 실납** | RF 모듈 납땜 | 입문용 1~2만원. through-hole용이면 충분 |
| **핀 헤더**(2.54mm) 또는 얇은 선 | RF 모듈 구멍에 연결 | 모듈에 핀 없이 구멍만 있어서 필요 |
| **암-암 점퍼선**(듀퐁) | 모듈 ↔ ESP32 연결 | 헤더 꽂은 뒤 연결용 |
| **Zigbee 동글** Sonoff ZBDongle-**P** | 거실2·주방·작업방 조명 | ★"P" 버전 (E 아님) |
| **USB-C→USB-A 어댑터/허브** | 동글을 Mac/Pi에 | Mac이 USB-C만이면 필수 |
| **라즈베리파이 4/5 키트** | 상시 서버 | 본체+전원+microSD(32GB+)+케이스 |
| **USB 충전기(5V)** ×2 | ESP32 상시 전원(안방/거실) | 흔한 폰 충전기 |

---

## 1. RF 모듈 납땜 (거실 로슬러 팬 + 무빙쇼파용)

**대상:** STX882(송신, 둥근 캔), SRX882(수신, 긴 파란 보드), 안테나 2개, ESP32 #2.

### 1-1. 납땜 기초 (처음이면)
1. 인두기 예열(~350℃). 팁에 납을 살짝 묻혀 코팅(tinning).
2. **패드(구멍)와 핀을 동시에** 인두로 2~3초 가열 → 납을 대서 녹여 채움 → 인두 떼기.
3. 광택 나는 원뿔 모양이면 성공. 방울지거나 흐릿하면 다시.
4. 옆 패드끼리 납이 붙지 않게(쇼트 주의).

### 1-2. 납땜할 것
- **STX882**: `DATA` `VCC` `GND` 구멍에 **핀 헤더 3개** + `ANT` 자리에 **안테나 1개**
- **SRX882**: `GND` `DATA` `VCC` 구멍에 **핀 헤더** + `ANT` 자리에 **안테나 1개**
  - (`CS` 핀은 일단 미납땜/미연결 — 수신 안 잡히면 그때 VCC에 연결)
- 안테나는 스프링 끝 **다리를 ANT 구멍에 넣고** 납땜.

## 2. RF 모듈 ↔ ESP32 #2 배선 (점퍼선)

```
STX882(송신)   ESP32 #2         SRX882(수신)   ESP32 #2
  DATA ───────  GPIO4             DATA ───────  GPIO5
  VCC  ───────  3.3V              VCC  ───────  3.3V   ★3.3V (5V 금지)
  GND  ───────  GND               GND  ───────  GND
```
- **⚠️ SRX882 VCC는 반드시 3.3V** (5V로 주면 DATA가 5V라 ESP32 손상 위험).
- GPIO는 예시(4/5). 스트래핑핀(0/2/15)만 피하면 다른 핀도 OK.
- 배선 후 **ESP32 #2를 Mac에 USB로** 연결(플래시·캡처용).

---

## 3. RF 리모컨 코드 캡처 (손: 리모컨 버튼 누르기)

1. (소프트) ESP32 #2에 캡처 펌웨어 flash — 별도 요청.
2. **로슬러 실링팬 리모컨**을 SRX882 가까이(30cm 내) 두고 **각 버튼**(속도/방향/조명 등)을 하나씩 누름.
3. **무빙쇼파 리모컨**도 각 버튼 누름.
4. 같은 버튼을 눌러도 **매번 코드가 다르면 = 롤링코드**(재생 불가) → 표시.
5. 캡처 로그는 소프트 쪽에서 분석.

---

## 4. Zigbee 동글 + Aqara H2 조명 페어링 (손: 스위치 조작)

1. **동글을 Mac(나중 Pi)에 USB로** 연결 (USB-A 어댑터 필요할 수 있음).
2. (소프트) 허브 `permitJoin: true`로 실행 — 별도.
3. **각 방 H2 스위치를 페어링 모드로** — 보통 **버튼 길게(5~10초) 눌러 LED 깜빡**일 때까지 (모델별 매뉴얼 확인).
4. 조인되면 로그에 IEEE 주소 뜸 → 소프트에서 config 등록.
5. 방마다 반복: 거실A, 거실B, 주방, 작업방.

---

## 5. ESP32 배치 + 전원 (BLE/RF 사거리)

- **안방 ESP32 #1**(BLE 실링팬) → **안방** 콘센트에 USB 충전기로 상주.
- **거실 ESP32 #2**(RF 팬/쇼파) → **거실**에 USB 충전기로 상주 (안테나 방향 신경).
- 둘 다 WiFi(`TP-Link_593C`)로 허브에 붙음 — 서버(Mac/Pi)엔 안 꽂음, 전원만.

---

## 6. 라즈베리파이 셋업 (상시 서버로 이전)

1. **microSD에 Raspberry Pi OS 굽기** (Raspberry Pi Imager, 다른 PC에서).
2. Wi-Fi/SSH 미리 설정(Imager 고급옵션) 또는 유선랜.
3. **Pi에 전원 연결 + 네트워크** 연결.
4. **Zigbee 동글을 Pi USB에** 꽂기 (Mac에서 빼서 Pi로).
5. (소프트) 허브 바이너리 + systemd 등록, Tailscale 설치 — 별도.
6. ESP32들은 그대로(WiFi) — Pi 브로커 IP만 소프트에서 갱신.

---

## 7. Apple TV 홈허브 (외부 원격용)

1. Apple TV를 TV+집 WiFi 연결.
2. **집 iCloud 계정 로그인** → iPhone 홈 앱에 "홈 허브 연결됨" 확인.
3. 전원만 꽂아두면 됨(재생 안 해도 대기 상태로 동작).

---

## 우선순위 (추천 순서)
1. **인두기 장만** → RF 모듈 납땜(§1) + 배선(§2)  ← 지금 시작점
2. **Zigbee 동글** 도착 → H2 조명 페어링(§4)  ← 납땜 불필요, 병행 가능
3. RF 코드 캡처(§3)
4. **라즈베리파이 이전**(§6) — 안정화되면
5. Apple TV(§7) — 외부 제어 필요할 때

> 각 단계의 **소프트웨어(펌웨어 flash, config, 캡처 분석)**는 이 문서에 없음 — 물리 작업 끝나면 그때 진행.
