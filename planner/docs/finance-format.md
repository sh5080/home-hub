# 재정 파일 규격

재정 화면은 가계부 앱이 내보내는 엑셀(xlsx)을 읽는다. **어떤 서비스의 파일인지, 시트·절·열 이름이 무엇인지는 코드에 없다.** 서버 데이터 폴더의 `finance-format.json`(또는 `PLANNER_FIN_FORMAT` 이 가리키는 파일)이 정한다. 이 파일은 저장소에 올리지 않는다.

내보내기 형식이 바뀌면 코드가 아니라 이 설정을 고친다. 파일이 설정과 다르면 올릴 때 어느 부분이 다른지(시트 이름, 절 제목, 거래 머리줄의 몇 번째 열) 알려준다.

## 기대하는 파일 모양

**요약 시트** (`summary_sheet`)
- B열에 `n.제목` 꼴로 절이 나뉜다. 읽는 절: `balance_section`(자산·부채), `invest_section`(투자), `loan_section`(대출). 그 밖의 절(개인정보 포함)은 읽지 않는다.
- 자산·부채 절: 한 줄에 왼쪽이 자산, 오른쪽이 부채.
  - 자산: B 분류(비어 있으면 윗줄 분류를 이어받음) · C 이름 · E 금액
  - 부채: F 분류 · G 이름 · I 금액
  - B열이 `balance_end` 로 시작하는 줄에서 끝난다. 그 줄의 합계 칸은 읽지 않는다(계산 안 된 수식일 수 있다).
- 투자·대출 절: 머리줄 다음부터 C 기관 · D 이름 · F 원금 · H 수익률(대출은 금리). 같은 이름의 자산·부채 항목에 붙는다.

**거래 시트** (`tx_sheet`)
- 1행은 머리줄. `tx_header` 가 열 문자 → 머리말을 정한다. 필요한 머리말: 날짜, 시간, 타입, 대분류, 소분류, 내용, 금액, 결제수단, 메모.
- 날짜는 엑셀 날짜 일련번호, 시간은 하루 중 비율.
- 타입 값은 `type_in` / `type_out` / `type_transfer` 셋 중 하나. 금액은 나가면 음수.

**파일 이름**: 끝에 `YYYY-MM-DD.xlsx`(기간의 끝날)가 있으면 그 날을 기준일로 쓴다. 없으면 올린 날.

## 설정 파일 필드

| 필드 | 뜻 |
|---|---|
| `source_name` | 화면에 보일 서비스 이름 |
| `how_to` | 파일 받는 법(화면 안내) |
| `summary_sheet`, `tx_sheet` | 시트 이름 |
| `balance_section`, `invest_section`, `loan_section` | 요약 시트의 절 제목(번호 뺀 부분) |
| `asset_groups` | 자산 분류 이름 → `liquid`(바로 쓸 수 있는 돈) · `saving` · `invest` · `insurance` · `pension`. 없는 분류는 `other` |
| `balance_end` | 자산·부채 표가 끝나는 줄의 B열 시작 말 |
| `tx_header` | 거래 시트 열 문자 → 머리말 |
| `type_in`, `type_out`, `type_transfer` | 거래 유형 값 |

서버는 시작할 때 이 파일을 읽는다. 필드가 빠졌으면 무엇이 빠졌는지 적고 시작하지 않는다. 파일이 없으면 재정 가져오기만 꺼진다.
